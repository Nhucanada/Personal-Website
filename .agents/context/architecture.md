# Architecture

## Repository Layout

Single-package frontend repository at the root (built with Vite 6 + TypeScript 5, tested with
Vitest + React Testing Library). The legacy `api/` Spring Boot module, Maven multi-module build,
Create React App toolchain, and Material UI dependencies were removed.

## Approximate size

- `src` (`.ts`/`.tsx`): ~2.7k lines across pages, components, static data, utilities, and tests.
- `src/styles` (`.css`): ~1.8k lines across `base.css`, `photography.css`, `selector.css`, and `software.css`.
- `scripts/optimize-photos.cjs`: ~120 lines.

## Tech stack

- **React 18** (`createRoot`, `StrictMode`, `React.lazy` for code-splitting Three.js) — entry `src/index.tsx`.
- **TypeScript 5**, `strict: true`.
- **Vite 6** (`vite.config.ts`) for fast dev server and production bundling (`dist/`).
- **React Router 6** for client-side routing.
- **Three.js** (`src/components/SoftwareThreeScene.tsx`), lazy-loaded into its own async chunk.
- **Lightweight SVG Icons** (`src/components/Icons.tsx`) + custom CSS (`src/styles/*.css`).
- **sharp** (devDependency) + macOS `sips` for the build-time photo optimizer (`scripts/optimize-photos.cjs`).
- **ESLint 9** (`eslint.config.js`) with `@eslint/js`, `typescript-eslint`, `eslint-plugin-react`,
  `eslint-plugin-react-hooks`, and `eslint-plugin-jsx-a11y` (`--max-warnings 0`).
- **Vitest + React Testing Library + jsdom** for unit and component tests (`src/**/*.test.{ts,tsx}`).
- **GitHub Actions CI** (`.github/workflows/ci.yml`) running `typecheck`, `lint:check`, `test`, and `build`.

## Deploy topology

- Static build output in `dist/` generated by `npm run build`.
- Netlify config in `netlify.toml` (`command = "npm run build"`, `publish = "dist"`) and SPA
  fallback in `public/_redirects` (`/* /index.html 200`).
- All photography and software portfolio data is static (`src/data/photography.ts` and
  `src/data/software.ts`).
